# Chrome Web Store · Firefox Add-ons listing (English)

**Name**: KeyHarbor

**Summary** (≤132 characters, same as the manifest `description`): Hand a site's login to a KeyHarbor agent session, and fill or save logins from the KeyHarbor vault on this Mac.

**Description**

KeyHarbor is a local vault for AI agents (Claude Code, Codex and others). This extension connects your everyday browser to it.

- **Hand off a site**: send a site you are already signed in to over to the agent's own browser session, so the agent does not have to sign in again. The browser asks once more before anything goes.
- **Fill and save**: after Touch ID, fill that site's login from the KeyHarbor vault on this Mac, or save a login you typed into the vault.

Values never leave this computer: the extension talks only to the KeyHarbor program on the same machine. Requires KeyHarbor (macOS); after installing it, run `keyharbor browser install-host` once.

Free and open source (MIT or Apache-2.0): https://github.com/LeeSwallow/KeyHarbor
