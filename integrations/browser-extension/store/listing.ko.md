# Chrome Web Store · Firefox Add-ons 리스팅 (한국어)

**이름**: KeyHarbor

**짧은 설명** (132자 이내, manifest `description`과 같게): Hand a site's login to a KeyHarbor agent session, and fill or save logins from the KeyHarbor vault on this Mac.

**자세한 설명**

KeyHarbor는 AI 에이전트(Claude Code, Codex 등)를 위한 로컬 금고입니다. 이 확장은 평소 쓰는 브라우저와 그 금고를 잇습니다.

- **사이트 넘기기**: 이미 로그인한 사이트를 에이전트의 전용 브라우저 세션으로 넘깁니다. 에이전트가 다시 로그인하지 않아도 됩니다. 넘기기 전에 브라우저 알림에서 한 번 더 묻습니다.
- **채우기·저장**: 이 Mac의 KeyHarbor 금고에 있는 그 사이트의 로그인을 Touch ID로 확인한 뒤 채우고, 새로 입력한 로그인을 금고에 저장합니다.

값은 이 컴퓨터 밖으로 나가지 않습니다. 확장은 같은 컴퓨터의 KeyHarbor 프로그램하고만 이야기합니다. KeyHarbor(macOS)가 설치되어 있어야 하며, 설치 뒤 `keyharbor browser install-host`를 한 번 실행합니다.
