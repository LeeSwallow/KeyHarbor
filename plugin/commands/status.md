---
description: Show KeyHarbor sessions, requests waiting for the user and recent use
allowed-tools: Bash(keyharbor:*)
---

Run `keyharbor status`, `keyharbor list`, `keyharbor vault requests` and
`keyharbor audit --limit 10`, and summarize them for the user: which sessions are open,
what waits for them, and what was used recently. Names only; the output has no values.
