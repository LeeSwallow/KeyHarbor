# ADR-0007. 넣지 않는 기능

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-03, R-07, R-10 |

## 맥락

OpenBrowser와의 기능 동등성(R-10)과 가입 전 단계 자동화(R-03)를 검토하면서, 일부 기능은 남용 위험이나 신뢰 모델 때문에 넣지 않기로 했다.

## 결정

**반목표(넣지 않음)**: identity별 프록시·시간대·언어 위장, CAPTCHA·봇 확인 자동 우회, 가상 번호·일회용 메일을 이용한 인증 통과.
**비목표(지금은 범위 밖)**: 원격 API·원격 MCP, 같은 계정 프로필 복제본, 인증 코드 수신(R-07), 쿠키 만료 추적·백그라운드 확인, 외부 금고 어댑터.

## 결과

- 대량 계정 생성·탐지 회피 도구로 쓰일 여지를 줄인다.
- CAPTCHA가 나오면 사람에게 넘겨야 한다(기존 인계 기능).
