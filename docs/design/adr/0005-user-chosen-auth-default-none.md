# ADR-0005. 관리 앱 인증은 사용자 선택, 기본값은 없음

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-16, R-20, R-21 |

## 맥락

사용자는 관리 앱 접근을 소유 기반·생체 인증으로 통제하는 것을 고민했지만(R-16), 인증은 OS·비밀번호·2FA·없음 중 사용자가 고르는 선택지일 뿐 강제하지 않겠다고 했다(R-20). 그리고 지금은 기본 인증 없음으로 구현하길 원한다(R-21).

## 결정

`Authenticator` trait과 scope(`OpenApp`, `Reveal`, `Edit`, `Export`, `PolicyChange`)를 정의하고, 이번에는 `NoneAuth`만 구현해 기본값으로 쓴다. 설정 화면은 현재 상태와 그 의미를 한 번 안내하고 막지 않는다. 같은 원칙으로 정책 기본값은 "모두 허용"이다.

## 결과

- 설치 직후 마찰이 없다.
- 기본 상태에서는 Mac 사용자 계정에 접근한 누구나 평문을 볼 수 있다. 이 사실을 숨기지 않는다.
- 이후 인증 구현은 trait에 붙이기만 하면 된다.
