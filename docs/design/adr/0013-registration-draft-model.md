# ADR-0013. 미등록 정보는 네 경로로 받고 draft로 먼저 저장한다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-27 |

## 맥락

에이전트가 작업 중 금고에 없는 정보(새 가입 비밀번호, 사용자가 직접 입력한 로그인, 카드·주소, 채팅으로 받은 API 키)가 필요해진다. 사용자는 로그인 후 자동 등록을 가장 좋게 보고, 폼을 띄우는 것도 괜찮다고 했다(R-27). 값이 에이전트를 거치면 P4에 어긋나고, 사람 확인을 기다리면 P3에 어긋난다.

## 결정

① `vault_generate`(KeyHarbor가 비밀번호 생성), ② submit 포착(감독자가 isolated world 스크립트로 사용자의 로그인 입력을 포착), ③ `vault_request`(KeyHarbor의 보안 입력 창 — 페이지 밖 Tauri 창), ④ `vault_put`(에이전트가 이미 아는 값)의 네 경로를 둔다. ①②④는 **draft**로 저장하고 즉시 placeholder로 쓸 수 있게 하며, `logged_in` 기록이나 사용자 확인으로 확정한다. 기존 항목의 값을 바꾸는 시도는 항상 새 버전 draft가 된다.

## 결과

- 에이전트가 멈추지 않고 값도 보지 않은 채 금고가 채워진다.
- 인젝션된 에이전트가 기존 비밀번호를 바꿔치기할 수 없다(draft 확정 필요).
- 페이지 스크립트 주입(②)은 실험이 필요하다.
