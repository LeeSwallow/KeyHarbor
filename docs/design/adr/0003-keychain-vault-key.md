# ADR-0003. 금고 키는 Keychain에 두고 생체 조건 없이 쓴다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-17, R-19 |

## 맥락

에이전트는 승인 없이 금고를 써야 한다(R-17). 그런데 금고 파일만 복사해 가서는 열 수 없어야 한다. 마스터 비밀번호나 Secure Enclave + 생체 조건으로 키를 감싸면 에이전트가 사용자 해제 전에는 멈춘다.

## 결정

무작위 256-bit 금고 키 하나를 macOS login keychain의 generic password(파일 기반 login keychain, 생체 조건 없음)로 저장한다. 필드 암호화 방식(단일 키 직접 암호화)은 [ADR-0011](0011-domain-split.md)의 도메인 키 계층으로 대체됐다. 이 ADR에서 유효한 부분은 VK의 보관 방식이다. 키가 없으면 새로 만들지 않는다.

## 결과

- macOS 로그인만으로 에이전트가 멈추지 않는다.
- 잠금 해제된 Mac에 접근한 사람이나 같은 OS 사용자 프로세스는 막지 못한다(문서에 명시, P6).
- 서명되지 않은 바이너리에서 Keychain 확인 창이 뜰 수 있다 — 1단계에서 검증한다.
- 공유 기능이 생기면 envelope encryption으로 확장해야 한다.
