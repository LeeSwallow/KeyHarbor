# ADR-0009. 브라우저 백엔드는 직접 띄우는 Chrome

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-05, R-06, R-19 |

## 맥락

ego-browser가 설치돼 있고 task space·handOff를 제공하지만(R-05), 사이트별 인증 관리는 없고(R-06) 외부 제품이다. 사용자는 외부 솔루션 없는 로컬 도구를 원한다(R-19).

## 결정

기존처럼 KeyHarbor 전용 프로필로 Chrome을 직접 실행한다. ego는 백엔드로 쓰지 않고 handOff UX만 참고한다. **[설계자 판단]**

## 결과

- 브라우저 수명 관리를 KeyHarbor가 계속 책임진다.
- Chromium 계열 외 브라우저 호환성은 보장하지 않는다.
