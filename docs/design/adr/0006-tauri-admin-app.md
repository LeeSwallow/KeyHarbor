# ADR-0006. 관리 앱은 Tauri로 만든다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-11 |

## 맥락

Google 비밀번호 관리자처럼 저장소를 보는 UI가 필요하다(R-11). localhost 웹 UI는 다른 로컬 웹 페이지·프로세스의 접근 면을 만들고, Swift 네이티브는 Rust 코어와 FFI가 필요하다.

## 결정

Tauri 데스크톱 앱으로 만들고 `kh-core`를 직접 링크한다. 네트워크 listener를 열지 않는다. 프런트엔드 스택은 구현자가 고른다.

## 결과

- 이후 OS 인증(Touch ID)을 플러그인으로 붙일 수 있다.
- 웹 프런트엔드 빌드 체인이 저장소에 추가된다.
