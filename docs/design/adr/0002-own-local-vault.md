# ADR-0002. 외부 금고 대신 앱 소유 로컬 금고를 둔다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-15, R-19 |

## 맥락

기존 [`architecture-proposal.md`](../../architecture-proposal.md)는 "비밀은 외부 금고(OpenKeylet 등)가 소유하고 KeyHarbor는 참조만 관리한다"로 결정했다. 사용자는 외부 솔루션 없이 모든 것을 손안에서 관리하길 원하고(R-19), 보안 처리·암호화 방식을 참고 사례를 바탕으로 직접 구현해 보길 원한다(R-15).

## 결정

KeyHarbor가 자체 금고를 소유한다. 암호 알고리즘은 RustCrypto 라이브러리를 쓰고, 키 계층·포맷·수명은 직접 설계한다([03](../03-security-whitepaper.md)). 외부 금고 어댑터는 만들지 않는다. **이 ADR은 기존 문서의 금고 결정을 대체한다.**

## 결과

- 치환·마스킹·금고가 같은 프로세스에 있어 평문 경로를 짧게 유지할 수 있다.
- 암호화 조합의 정확성 책임을 KeyHarbor가 진다. 누출 검사와 포맷 테스트가 필수가 된다.
- `bind-account`(OpenKeylet 이름 참조)와 `session_account`는 제거·대체한다.
