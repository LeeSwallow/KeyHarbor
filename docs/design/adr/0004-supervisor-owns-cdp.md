# ADR-0004. 감독 프로세스가 CDP를 소유하고 에이전트에는 도구만 준다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-10, R-12 |

## 맥락

프로토타입은 CDP WebSocket 주소를 에이전트에 직접 준다. 이 경우 에이전트가 브라우저 전권을 가지므로 마스킹·정책·origin 확인을 강제할 수 없다. OpenBrowser는 브로커가 CDP를 쥐고 navigate·click·type 같은 도구를 제공한다(R-10).

## 결정

감독자가 Chrome을 `--remote-debugging-pipe`로 실행해 CDP를 소유한다. 에이전트는 MCP의 `browser_*` 도구를 쓰고, MCP 서버는 세션별 Unix socket으로 감독자에 명령을 전달한다. raw CDP(`--allow-cdp` + `cdp: true`)는 선택 기능으로 남기되, 켜면 보호가 우회된다는 경고를 표시한다.

## 결과

- placeholder 치환과 응답 마스킹을 한 곳에서 강제할 수 있다.
- 에이전트는 도구 범위 안에서만 브라우저를 다룬다. 부족한 도구는 추가해야 한다.
- 감독자가 커지고 IPC가 생긴다. 감독자 장애 시 브라우저 명령이 모두 실패한다.
